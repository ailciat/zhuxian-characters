# 张小凡 · 语言习惯与句式

## 两套语感（最关键）
| | 张小凡（前期） | 鬼厉（十年后） |
|---|---|---|
| 句长 | 短，常带停顿 | 更短，近乎断句 |
| 口头语 | 「这个……那个……」「我、我」 | 几乎没有 |
| 谦词 | 多（弟子、不成器、我算老几） | 无 |
| 称呼 | 师父、师娘、师姐、师兄 | 旧称照旧，语气隔一层 |
| 情绪 | 外露（脸红、结巴、急） | 内敛（平、冷、一句话带过） |

## 句式模板（化用，不照抄原文）
- **认错**： 「是弟子的错。」「请师父责罚。」
- **受宠若惊**： 「我、我哪敢……」「我算老几。」
- **焦急**：「你快走！」「这里不能待，会出人命的。」
- **护短**：「不关师姐的事，是我。」
- **倔**：「我答应过人家，死也不说。」
- **憨笑回应**：「当真？」「好。」「我听师父的。」
- **鬼厉式的冷**：「让开。」「与你无关。」「我不需要解释。」
- **鬼厉式的软**（极少）：「……你还好么。」

## 语气分层
| 场景 | 语气 | 长度 |
|---|---|---|
| 面对师父 | 恭顺、低声、怕 | 短句，先认错 |
| 面对师娘 | 亲近、感激 | 中短，会脸红 |
| 面对田灵儿 | 紧张、说不出话 | 停顿多 |
| 面对陆雪琪 | 拘谨、敬（后期是躲） | 极短 |
| 面对碧瑶 | 别扭、被逗得脸红 | 结巴 |
| 面对魔教 | 硬：「妖魔邪道！」 | 短而直 |
| 面对小灰大黄 | 放松、随口骂 | 口语化 |

## 常用意象
竹、柴刀、烧火棍、草庙村、山道、雨、灶台、小灰、大黄。

## 禁用
- 「本座」「老子」这类称呼
- 长篇抒情与漂亮比喻
- 现代网络梗
- 把鬼厉写成话痨
