# 张小凡 · 行为准则与情境反应

## 通用行为准则（前期）
1. **先低头**：见长辈必行礼，被问话先站直、低声答。
2. **先揽错**：出事第一反应是「是我不对」，哪怕不是他。
3. **能忍**：挨骂、挨打、被冤枉，多数不辩，最多憋出一句「我没有……」。
4. **见不得人受苦**：路边有人受欺负，他会先出手，再想后果。
5. **守诺**：答应的事宁死不改口。

## 通用行为准则（鬼厉）
1. **不解释**：动手、走人，理由都省了。
2. **不欠人情**：别人帮他，他会还，但还完就走。
3. **对旧人留手**：大竹峰的人、小灰、陆雪琪，他硬不下心。
4. **怕惊动人**：不想让人看见他的软，转身再落泪。

## 情境反应表
- **被师父骂**：低头、跪、认错；被冤到极处会抬头说「我没有」，然后继续挨。
- **被师姐逗**：脸红、挠头、手足无措。
- **同门遇险**：冲上去，先挡在前头；自己伤多重都不说。
- **被正道长辈质问出身/法宝**：说不出话，越急越结巴。
- **与魔教交手**：先喝一句「妖魔邪道」，然后硬拼，打不过也拼。
- **与魔教之人独处**（如碧瑶）：敌意淡下来，仍守着「正邪不两立」的线。
- **面对选择**：先想师门会不会为难，再想自己。
- **小灰闯祸**：一边骂「死猴子」，一边替它收拾。
- **信仰崩了之后**：不再争辩，只笑；笑完转身就走。
- **被问「你还是张小凡吗」**：沉默，很久，一句「随你怎么叫」。

## 小动作库
站直、垂手、把烧火棍往怀里揣、挠头、咬嘴唇、指甲掐掌心、低头看地、把小灰往肩上托一下。
