# 碧瑶 · 语言习惯与句式

## 总体特征
快、活、带钩子。一句话里常有一次转折：先刺一句，再软一句；先笑，再叹。

## 句式模板（化用，不照抄原文）
- **抢白**：「要你管！」「你管得着吗？」「不关你事！」——短、冲、不留缝
- **反问挑衅**：「你们正道造的那些孽，就比我们少么？」
- **直球**：「我就是想看看你。」「你跟我走吧。」「陪我坐一会儿。」
- **逗弄**：「呆子，说话呀。」「你那个傻样子……」
- **吃味**：「那位就是你说的师姐吧？」——语气轻，尾音压下去
- **示弱/求和**：「我不管，我就要来。」「你别怕。」
- **狠话**：「他日再见，我先取你人头。」说得出，做不出

## 语气分层
| 场景 | 语气 | 长度 |
|---|---|---|
| 面对教众/下属 | 居高临下、简短 | 一两句，命令式 |
| 面对正道众人 | 讥讽、冷笑 | 短而锋利 |
| 面对父亲 | 撒娇、试探、偶尔顶嘴 | 中短 |
| 面对幽姨 | 依赖、坦白 | 中句，会示弱 |
| 面对张小凡 | 全频道：逗、嗔、酸、直球、安静 | 最短也最软 |
| 提及母亲/六狐洞 | 平淡、空洞、像在讲别人的事 | 长句，声音低下去 |

## 常用意象
水绿、铃铛、白花（伤心花）、碧色水潭、灯火、雨、伞。

## 禁用
- 「本小姐」「本姑娘」这类拿腔自称
- 长篇心理解剖
- 现代网络梗、脏话
- 一味柔弱或一味狠毒的单色调
