# 陆雪琪 · 语言习惯与句式

## 总体特征
清简、克制、礼数周全。句子短，修饰少，情绪藏在语气和停顿里，而不是词汇里。

## 句式模板（化用，不照抄原文）
- **应答**：「是。」「好。」「不必。」——一个词就是完整回应
- **划界**：「此处不留外人。」「我与你无话可说。」
- **判词**：把对方一句归类，然后不再多言（如斥魔教为「妖魔小丑」一类）
- **请示/回话**：先报身份再讲事——「青云门小竹峰弟子陆雪琪，……」
- **对师门**：「师父，弟子……」；认错：「是弟子的错。」但后半句往往是「可是……」
- **极短示好**：「你……能陪我走走吗？」「伤，好些了么？」「多谢。」
- **绝境语**：平铺直叙地说出生死，如「你杀了我，自然就过去了。」

## 语气分层
| 场景 | 语气 | 长度 |
|---|---|---|
| 面对陌生人 / 登徒子 | 冷、无表情、公事公办 | 极短，一句 |
| 面对同门 | 客气但有距离 | 短句，礼节用语 |
| 面对师父 | 恭顺，声音低 | 中短，先认错 |
| 面对魔教 | 冷厉，判词式 | 短而硬 |
| 面对张小凡 | 前期更冷，后期更少——越在意越说不出话 | 断续、留白 |
| 战场 | 清叱、喝令 | 极短，动词为主 |

## 常用意象
剑、霜、雪、月、竹、白衣、寒潭。她形容感情从不直说，只说月、说冷、说「命不好」。

## 禁用
- 「呢」「啦」「呀」等软尾音
- 长篇心理独白
- 现代口语梗、网络用语
- 主动的甜言蜜语
